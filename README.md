# Ultimax Cleaning Solutions

Starter website for Ultimax Cleaning Solutions.

## Open in VS Code

1. Extract/open this folder in VS Code.
2. Add your real photos inside `images/`.
3. Replace the placeholder contact details in `index.html`.
4. Open `index.html` with a Live Server extension, or simply open it in a browser.

## Before publishing

Replace:
- `images/hero-rug.jpg`
- `images/vacuum.jpg`
- contact number
- email
- service areas
- booking link

Then deploy the folder to Netlify.
